# SHINOBI: Shadow Clash (2D prototype)

A single-file HTML5 canvas fighting-game prototype inspired by the uploaded reference footage: dark desert arena, fast stick-style fighters, quick dashes, jump movement, chained attacks, jutsu projectiles, block, hit stun, knockback and ultimate effects. Includes 16 selectable original fighter variants and touch controls for mobile.

## Run locally
Open `index.html` in a modern browser. Internet is not required; the game uses no external libraries.

## Publish on GitHub Pages
1. Create/open your GitHub repository.
2. Upload `index.html` and `README.md` to the repository root (replace the previous prototype's `index.html`).
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
5. Open the Pages URL on Android. Landscape mode is recommended.

## Controls
- Phone: on-screen left/right, jump, guard, hit, heavy, dash, jutsu and ultimate.
- Keyboard: A/D or arrows move, W/Up jump, J hit, K heavy, L jutsu, Shift dash, I ultimate, S/Down guard.

## Scope
This is a playable prototype, not a finished commercial game. The fighters are drawn procedurally on canvas rather than using copied proprietary sprite sheets. More advanced frame-by-frame animation, sound, additional arenas, character-specific move trees and tuning still need iteration.
